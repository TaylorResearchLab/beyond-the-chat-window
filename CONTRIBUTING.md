# Contributing to the manuscript

This manuscript uses a human-governed, User-mediated workflow.

## Before editing

1. Check the Notion Collaboration Log.
2. Identify the current canonical branch and accepted manuscript state.
3. Confirm the requested task, privacy boundary, and acceptance condition.
4. Create a bounded branch.

## Pull requests

A pull request must state:

- the requested manuscript change;
- sections and files changed;
- claims or citations added or removed;
- whether the workflow figure or public template changed;
- Manubot build status;
- known limitations;
- the corresponding Notion Collaboration Log entry.

The User reviews and merges all pull requests.

## AI tools

GPT and Claude may propose text, code, figures, citations, and reviews. They are not authors and cannot merge or publish independently. All accepted content is the responsibility of the human author.
