## Implementation materials

Supplementary Note S1 separates the practical implementation materials from the retrospective evaluation reported in the main paper. It provides a quick-start guide for establishing human authority, a structured shared record, a Collaboration Log schema, repository and execution custody, review and approval rules, context reorientation, project-wide realignment, handoffs, troubleshooting, and release. The guide is followed by a completed synthetic work contract, example assignment, example Collaboration Log record, structured handoff, and compact reusable template. These materials are intended to be adapted to the project's scientific risk, privacy requirements, duration, institutional policies, and available software rather than copied without review.
