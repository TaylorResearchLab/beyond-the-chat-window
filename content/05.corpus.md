# Corpus and observations

The retrospective corpus comprises private project workspaces in which the same record-keeping pattern was applied. At the August 13, 2026 snapshot, seven standardized Collaboration Logs across six workspaces contained 728 records. This was a time-bounded observation of ongoing projects, not a project-completion boundary. Additional specialized and reflexive logs were retained qualitatively and excluded from this total. Projects are reported by collaboration type rather than scientific domain because named collaborators did not consent to disclosure of their work and because the collaboration function is what this paper examines.

The observed collaboration types were: code development and review; structural coding, state management, and literature retrieval with verification; structural coding and analysis review; code development, figure regeneration, independent recomputation, and citation audit; and creative project consistency and project tracking. The User did not use either platform to author scientific content; the platforms were used for project and code management, review, retrieval, and consistency checking. This manuscript is the deliberate exception.
