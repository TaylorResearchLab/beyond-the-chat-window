# Future evaluation

An adoption study should first test whether investigators who did not develop the workflow can establish the shared record, complete a task-review-acceptance cycle, and resume from a handoff using the supplied materials. Useful outcomes include setup failures, missing provenance, successful artifact retrieval by the reviewer, accuracy of accepted-state reconstruction, and the time required for instruction and maintenance. Comparing the written protocol with Skill-assisted onboarding would evaluate the packaging contribution separately from the workflow itself.

A prospective effectiveness study should compare matched tasks under several conditions: one AI platform, multiple named sessions from one provider, the User-mediated two-provider workflow, and an automated workflow using model APIs. Assignments, exposure, reviews, corrections, and acceptance decisions should be recorded when they occur. Outcomes defined before data collection should include substantive defect detection, reproducibility of accepted results, time to acceptance, revision burden, User review time, token use, and monetary cost.

A multi-investigator study would test an arrangement in which no single person holds continuous project memory, final authority, and access control. It would require explicit responsibility for record maintenance and a process for resolving disagreements among investigators as well as model outputs. Prospective measurement itself adds work, so evaluation should distinguish records needed for reproducibility from additional measurement requirements that interfere with active research.
