# Limits of the tooling

Three constraints emerged in this implementation and are likely relevant to comparable workflows.

**The connector behavior observed here was not transactional, and a success response was not confirmation.** Creating a record without an explicit parent places it outside the intended database. It exists, it is reachable by URL, and it is absent from every query that would reveal it. Moving it back succeeds while silently discarding every structured property. The two failure modes are independent, and the repair for the first causes the second. This occurred twice during manuscript preparation.

**In the implemented schema, review routing was stored as mutable state rather than as an append-only event.** Clearing a review flag after completing a review is good hygiene and destroys the evidence that the review occurred. Any analysis of routing therefore undercounts completed review, and the undercount is invisible.

**In the User-authenticated integration used here, agent-initiated actions were unauditable from repository metadata alone.** When an assistant acts through a User-authenticated integration, the platform records the authenticated identity. A connector-initiated commit and a manual push are indistinguishable in repository metadata. During this work, one commit was written by an assistant through the User's scoped integration and another was pushed manually by the User; both are attributed identically. Consequently a reader cannot reconstruct initiation from the repository, and the Collaboration Log is the only record that distinguishes them. This is a strong argument for keeping such a log, and it carries an unavoidable limitation: the log is attested by participants rather than by the platform, so its provenance claims are only as good as the logging discipline behind them.

Additionally, the Notion analysis path was constrained: cross-data-source aggregation required a higher subscription tier, and query results were returned into model context rather than directly to a file, which was not a viable bulk export path at corpus scale.
