# Introduction

Scientific work rarely fits inside a chat session. A project may run for months, span several repositories, involve data that cannot leave a protected environment, and draw on more than one model provider. Chat interfaces are organized around none of these properties. Separate sessions do not reliably inherit the prior session's state, context is often reconstructed manually, and chat alone does not preserve why a decision was made or who made it.

The usual response is orchestration: a framework that lets model instances exchange messages and execute steps with limited human involvement [@arxiv:2308.08155; @arxiv:2308.00352; @arxiv:2307.07924]. This paper describes the opposite arrangement. Two commercial assistants from competing providers, GPT and Claude, never exchange messages directly. A human User routes attention between them through a durable structured record, and retains acceptance, merge, and release authority throughout.

The arrangement is not autonomous and does not aim to be. Its claim is narrower: that a shared, structured, human-governed record makes multi-session, multi-provider scientific work traceable and reviewable using commodity tools, and that the resulting record supports FAIR practice [@doi:10.1038/sdata.2016.18] better than chat transcripts do.
