# Failure modes and controls

| Failure mode | Control |
| --- | --- |
| Session amnesia across weeks | Canonical-state pages and state-anchoring handoff records |
| Fluent but unverified assertion | Evidence hierarchy; acceptance requires recorded evidence, not model confidence |
| Cross-agent agreement mistaken for corroboration | Agreement after exposure is recorded as sequential, not independent |
| Silent divergence between record and artifact | Commit SHA and artifact location recorded in the log entry |
| Decisions made in conversation and never recorded | Contract requires every material output to be logged |
| Results recorded without the means of producing them | Contract requires code, inputs, and outputs stored together |
| Connector writes that fail silently | Read-back verification after every create or move |
| Mutable state overwritten during analysis | Freeze and export before any measurement |
